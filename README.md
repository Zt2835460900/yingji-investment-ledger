# 盈迹 · 个人投资收益账本

盈迹用于记录基金、股票和 ETF 的交易、资金进出、定投计划与资产配置，并以专业口径分别计算绝对盈亏、TWR 与 XIRR。

## 已实现功能

- 多投资账户，账户独立显示资产、盈亏和年化 XIRR
- 买入、卖出、分红、费用、入金与出金流水
- 移动加权平均成本，部分卖出自动匹配剩余成本
- 已实现、未实现、分红收入、总收益与手续费统计
- 日频 TWR、年化 XIRR、月度盈亏与累计收益曲线
- 最大回撤、年化波动率、夏普比率和日胜率
- 定投计划、目标配置、偏离提醒
- 手动价格/净值更新
- CSV、XLSX、XLS 交易导入及 JSON 数据备份
- 中文响应式界面，适配手机与电脑

## 专业计算口径

- 金额按 `1/10,000 CNY` 的整数保存；价格、份额按 `1/1,000,000` 的整数保存，数据库不保存二进制浮点金额。
- 买卖是账户内部资产转换，不是账户外部现金流。
- 只有入金和出金参与账户级 XIRR，并从 TWR 中剔除。
- XIRR 使用实际日期和 365 天年基准；检测到多个可能根时返回“无法给出唯一结果”。
- 当前只有日终估值时，TWR 使用明确的日初现金流约定，并在界面标注为估算口径。
- 夏普比率当前默认无风险利率为 0%，年化交易日数为 252。

详细公式见 [`docs/CALCULATIONS.md`](docs/CALCULATIONS.md)。

## 数据库

Cloudflare D1（SQLite 兼容）保存账户、产品、流水、价格、定投和目标配置，Drizzle schema 位于 `db/schema.ts`，迁移文件位于 `drizzle/`。

金额字段使用缩放整数：

- `gross_amount_units`、`fee_units`、`tax_units`：金额 × 10,000
- `quantity_units`：份额 × 1,000,000
- `price_units`：价格 × 1,000,000
- `target_bps`：目标比例的基点，例如 67% = 6,700

运行时会以单条 prepared statement 创建所需表，并通过唯一外部流水号避免重复导入。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

质量检查：

```bash
npm test
npx tsc --noEmit
npm run build
```

## 部署

推荐部署到 Cloudflare Sites：构建产物由 `vinext` 生成，D1 绑定名为 `DB`，数据库迁移随版本发布。

远程服务器可以作为固定入口，通过 Nginx 转发或跳转到私有 Sites 地址。个人财务数据不建议使用未加密的 IP 直连；应使用 HTTPS 和访问控制。

## 导入格式

交易模板字段：

```text
账户名称,交易类型,交易日期,产品代码,成交份额,成交价格,成交金额,手续费,税费,备注,外部流水号
```

交易类型使用：`BUY`、`SELL`、`DEPOSIT`、`WITHDRAWAL`、`DIVIDEND`、`FEE`。买卖成交金额可以留空，由份额乘价格计算；外部流水号非空时必须唯一。

## 重要说明

盈迹是个人记录和分析工具，不构成投资建议。自动行情、汇率归因、证券转入转出和逐笔 FIFO 是后续扩展项；当前基准币种为人民币，成本法为移动加权平均。
