# 盈迹 · 个人投资收益账本

盈迹用于记录基金、股票和 ETF 的交易、资金进出、定投计划与资产配置，并以专业口径分别计算绝对盈亏、TWR 与 XIRR。

## 已实现功能

- 多投资账户，账户独立显示资产、盈亏和年化 XIRR
- 买入、卖出、分红、费用、入金与出金流水
- 移动加权平均成本，部分卖出自动匹配剩余成本
- 已实现、未实现、分红收入、总收益与手续费统计
- 支付宝式总资产口径：持仓市值与可用现金共同计入资产，卖出款、分红和盈亏不会漏算
- 交易录入中输入 6 位基金/ETF 代码即可自动匹配并收录产品，无需先去产品中心建档
- 账户支持安全删除；存在流水或定投计划时会阻止删除，避免误删历史数据
- 支持产品级买入费率、平台折扣、卖出/赎回费率与最低手续费
- 场外基金真实数据同步：名称、账户类型、所选交易日历史净值、直销标准费率、天天基金优惠费率和赎回费分档
- 页面每 3 分钟检查净值，独立服务器每 5 分钟后台检查；显示估值日期、同步时间及官方/备用来源
- 每笔交易记录购买渠道；赎回费按 FIFO 持有天数匹配真实费率档位
- 日频 TWR、年化 XIRR、月度盈亏与累计收益曲线
- 最大回撤、年化波动率、夏普比率和日胜率
- 定投计划、目标配置、偏离提醒
- 手动价格/净值更新
- CSV、XLSX、XLS 交易导入及 JSON 数据备份
- 中文响应式界面，适配手机与电脑

## 专业计算口径

- 金额按 `1/10,000 CNY` 的整数保存；价格、份额按 `1/1,000,000` 的整数保存，数据库不保存二进制浮点金额。
- 所有账户统一采用完整现金账户口径；`总资产 = 持仓市值 + 可用现金 = 累计净投入 + 累计收益`。
- 没有预先记录入金时，买入会自动补足当笔所需投入；复用卖出款或分红再次买入不会重复增加本金。
- 卖出款与分红保留在可用现金中，只有明确记录出金才会离开总资产并减少累计净投入。
- 所有外部投入与出金都会进入 XIRR，并从 TWR 中剔除，避免追加资金扭曲收益率。
- XIRR 使用实际日期和 365 天年基准；检测到多个可能根时返回“无法给出唯一结果”。
- 当前只有日终估值时，TWR 使用明确的日初现金流约定，并在界面标注为估算口径。
- 夏普比率当前默认无风险利率为 0%，年化交易日数为 252。

详细公式见 [`docs/CALCULATIONS.md`](docs/CALCULATIONS.md)。

## 数据库

Cloudflare D1（SQLite 兼容）保存账户、产品、流水、价格、定投和目标配置，Drizzle schema 位于 `db/schema.ts`，迁移文件位于 `drizzle/`。

金额字段使用缩放整数：

- `gross_amount_units`、`fee_units`、`tax_units`：金额 × 10,000
- `quantity_units`：份额 × 1,000,000
- `price_units`：价格 × 1,000,000
- `target_bps`：目标比例的基点，例如 67% = 6,700

运行时会以单条 prepared statement 创建所需表，并通过唯一外部流水号避免重复导入。

## 部署

Cloudflare Sites 与独立服务器均可运行。服务器版通过本地 Workers 运行时保存 SQLite 兼容数据库，并由 Nginx 提供 HTTPS 与访问控制。

当前独立部署地址为 `https://yingji.kivelo0017.xyz`。应用和数据均保存在服务器，服务配置与 Nginx 模板位于 `deploy/`。服务器配置包含 HTTPS、访问认证、请求限流、安全响应头、跨站写入拦截、最小权限数据目录、每 5 分钟净值同步，以及每天一次的 SQLite 与 JSON 双备份（保留 30 天）。在“数据与设置 → 安全与登录”中输入当前密码，即可自行修改登录账号和密码；新密码使用独立的加盐哈希文件保存，不进入投资数据库。

## 导入格式

交易模板字段：

```text
账户名称,交易类型,交易日期,确认日期,产品代码,成交份额,成交价格,成交金额,手续费,税费,备注,外部流水号
```

`确认日期`为基金申购或赎回的实际份额确认日期，可留空，且不能早于交易日期。它用于账单核对与明细展示；持仓、现金流、TWR 和 XIRR 仍以实际交易日期计算，避免把基金公司的处理延迟误当成投资收益。

交易类型使用：`BUY`、`SELL`、`DEPOSIT`、`WITHDRAWAL`、`DIVIDEND`、`FEE`。买卖成交金额可以留空，由份额乘价格计算；外部流水号非空时必须唯一。

交易界面的手续费留空时，系统按产品费率规则自动估算；填写金额时则以基金公司、券商或平台的实际账单为准。买入费用计入持仓成本，卖出费用从卖出收入中扣除，二者都会进入总收益和费用统计。

## 重要说明

盈迹是个人记录和分析工具，不构成投资建议。当前自动同步覆盖可识别的场外基金/ETF 净值；汇率归因、证券转入转出和逐笔 FIFO 成本法仍是后续扩展项。当前基准币种为人民币，成本法为移动加权平均。
