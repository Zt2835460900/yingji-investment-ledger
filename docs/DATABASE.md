# 数据库设计

| 表                   | 用途               | 关键约束                         |
| -------------------- | ------------------ | -------------------------------- |
| `accounts`           | 投资账户           | CNY 基准币种、移动加权成本       |
| `instruments`        | 基金、股票、ETF    | 产品代码唯一                     |
| `ledger_entries`     | 资金与交易统一账本 | 账户日期索引；非空外部流水号唯一 |
| `prices`             | 历史价格/净值      | 产品与日期联合唯一               |
| `recurring_plans`    | 定投规则           | 账户、产品、金额和下一期日期     |
| `allocation_targets` | 目标配置           | 每个产品一个目标                 |
| `app_meta`           | 初始化版本         | 键值唯一                         |

数据库不缓存不可追溯的“最终收益数字”。页面读取原始流水与价格后由统一计算引擎重建结果，因此修改历史交易不会留下旧口径残值。
