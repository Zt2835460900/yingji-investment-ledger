# 收益与风险计算规范

## 1. 资金和交易事件

所有账户统一采用完整现金账户口径：

- 入金增加可用现金和外部投入，出金减少可用现金和累计净投入。
- 买入是现金转为持仓；若没有先录入入金，只自动补足该笔买入所缺的现金，并把补足额计为外部投入。
- 卖出是持仓转为可用现金，分红也进入可用现金；二者不会被误当成资金离开账户。
- 再次买入时优先使用已有现金，不重复增加投入本金。
- 独立费用优先从现金扣除，现金不足部分才作为自动补足的外部投入。

买入总成本：

```text
份额 × 价格 + 手续费 + 税费
```

卖出净收入：

```text
份额 × 价格 - 手续费 - 税费
```

手续费留空时按产品规则估算：

```text
直销买入手续费 = max(成交金额 × 基金标准申购费率, 最低手续费)
天天基金买入手续费 = max(成交金额 × 渠道当前优惠费率, 最低手续费)
卖出手续费 = Σ(各 FIFO 批次卖出金额 × 该批次持有期对应赎回费率)
```

自动结果使用整数金额单位计算并四舍五入到 0.0001 元。若平台账单给出实际费用，实际费用优先于自动估算。

赎回持有期按自然日计算，份额按先进先出（FIFO）匹配费率；持仓成本和已实现收益仍按账户的移动加权平均成本法计算。两者分别解决“适用哪档赎回费”和“卖出对应多少成本”的问题。

移动加权平均成本：

```text
新单位成本 = (原剩余成本 + 新买入总成本) / (原份额 + 新份额)
```

部分卖出的匹配成本按卖出份额占卖出前总份额的比例从剩余成本中移除。

## 2. 盈亏

```text
已实现收益 = 卖出净收入 - 匹配成本
未实现收益 = 当前证券市值 - 剩余持仓成本
当前总资产 = 当前证券市值 + 可用现金
累计总收益 = 当前总资产 - 累计净投入
当前总资产 = 累计净投入 + 累计总收益
```

分红、利息与手续费单独列示，便于核对总收益来源。

## 3. XIRR

投资者视角下，入金与直接买入时的现金补足为负现金流，出金为正现金流；账户内部的买入、卖出和分红不是外部现金流。报告期末总资产作为最后一笔正现金流：

```text
Σ CFᵢ / (1 + r)^((dᵢ - d₀) / 365) = 0
```

系统先在 `-99.99%` 至高正收益区间进行对数网格扫描：

- 没有正负两类现金流：不计算；
- 没有根：不计算；
- 发现多个符号变化区间：认为可能存在多个 IRR，不输出伪精确结果；
- 只有一个区间：使用二分法求解。

## 4. TWR

当前日终估值模式采用“外部现金流在日初可投资”的一致约定：

```text
日收益率 = (日末资产 - 上日末资产 - 当日净外部现金流)
           / (上日末资产 + 当日净外部现金流)
累计 TWR = Π(1 + 日收益率) - 1
```

追加资金因此不会被视为收益。若未来保存每一笔外部现金流发生前后的组合估值，可切换为 True TWR。

## 5. 风险

```text
年化波动率 = 日收益率样本标准差 × √252
夏普比率 = 日平均超额收益 × 252 / 年化波动率
财富指数 Wₜ = Π(1 + rₜ)
回撤 DDₜ = Wₜ / max(W₀ ... Wₜ) - 1
最大回撤 = min(DDₜ)
```

日胜率仅统计收益不等于零的估值日。无风险利率当前默认为 0%，界面会明确提示。
