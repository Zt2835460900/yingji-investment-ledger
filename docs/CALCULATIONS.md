# 收益与风险计算规范

## 1. 资金和交易事件

账户外部现金流只有入金和出金。买入、卖出、分红和费用均在账户内部结算，不作为账户级 TWR 的外部现金流。

买入总成本：

```text
份额 × 价格 + 手续费 + 税费
```

卖出净收入：

```text
份额 × 价格 - 手续费 - 税费
```

移动加权平均成本：

```text
新单位成本 = (原剩余成本 + 新买入总成本) / (原份额 + 新份额)
```

部分卖出的匹配成本按卖出份额占卖出前总份额的比例从剩余成本中移除。

## 2. 盈亏

```text
已实现收益 = 卖出净收入 - 匹配成本
未实现收益 = 当前证券市值 - 剩余持仓成本
累计总收益 = 当前总资产 + 累计出金 - 累计入金
```

分红、利息与手续费单独列示，便于核对总收益来源。

## 3. XIRR

投资者视角下，入金为负、出金为正，报告期末总资产作为最后一笔正现金流：

```text
Σ CFᵢ / (1 + r)^((dᵢ - d₀) / 365) = 0
```

系统先在 `-99.99%` 至高正收益区间进行对数网格扫描：

- 没有正负两类现金流：不计算；
- 没有根：不计算；
- 发现多个符号变化区间：认为可能存在多个 IRR，不输出伪精确结果；
- 只有一个区间：使用二分法求解。

## 4. TWR

当前日终估值模式采用“外部现金流在日初可投资”的一致约定：

```text
日收益率 = (日末资产 - 上日末资产 - 当日净外部现金流)
           / (上日末资产 + 当日净外部现金流)
累计 TWR = Π(1 + 日收益率) - 1
```

追加资金因此不会被视为收益。若未来保存每一笔外部现金流发生前后的组合估值，可切换为 True TWR。

## 5. 风险

```text
年化波动率 = 日收益率样本标准差 × √252
夏普比率 = 日平均超额收益 × 252 / 年化波动率
财富指数 Wₜ = Π(1 + rₜ)
回撤 DDₜ = Wₜ / max(W₀ ... Wₜ) - 1
最大回撤 = min(DDₜ)
```

日胜率仅统计收益不等于零的估值日。无风险利率当前默认为 0%，界面会明确提示。
